# Grokbot

Grokbot runs Plumber through the grokbot. The instructions are already in this folder. You don't paste a prompt, and you don't open a separate chat product.

## The step

Point your coding agent at this file:

`https://raw.githubusercontent.com/crocsarecool/plumber/main/grokbot/AGENTS.md`

## What happens next

The agent follows that file in your app: set Plumber up, report something that went wrong, or update. It reads the same setup steps, formats, and maintain skill as the other doors.

Cases stay in the app's data folder, on that machine. A fix waits on a branch until you merge it. A maintain run makes at most two fixes. Nothing uploads what people typed, said, or asked.

Gitbot is the other door. Grokbot does not call it.
